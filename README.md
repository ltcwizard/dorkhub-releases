# DorkHub releases

Downloads for **DorkHub**, the family home base: accounts, the DorkRequest
wishlist, and **DorkChat** (family instant messaging).

👉 **[Get the latest release](../../releases/latest)**

| | Download |
|---|---|
| **Windows 10/11** | `DorkHub-vX.Y.Z-windows-x64.zip`: unzip somewhere permanent (e.g. `C:\Dork\`) and run `DorkHub\DorkHub.exe` |
| **Linux Mint 22 / Ubuntu 24.04** | `DorkHub-vX.Y.Z-linux-x86_64.tar.gz`: unpack and run `DorkHub/DorkHub` |

DorkHub runs on the always-on computer. Everyone else just opens it in a
browser: `http://<that computer's address>:6800` (and `/chat/` for DorkChat).

**Updating:** close the old DorkHub window, then replace the `DorkHub` folder.
Accounts, requests and chats are kept; they live in `%APPDATA%\DorkHub`
(Windows) or `~/.local/share/dorkhub` (Linux), not in the download.

`SHA256SUMS.txt` in each release lets you check the downloads weren't corrupted.
